OFLC County Wage Map

County-level view of prevailing wage levels by year and SOC code.

Counties inherit the local wage-area value published by OFLC. Select a wage year, job code, source, and wage level to inspect annual wages on the yearly map.

Scope

This dashboard is built from official FLAG wage downloads from `2019-2020` through `2025-2026`, current as of August 20, 2025.
